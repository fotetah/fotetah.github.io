Grant Seeker — Privacy notice

Publication date: November 13, 2026. Contact: fotetech@gmail.com.

Purpose and audience

Grant Seeker is a private tool operated by its owner to research grant opportunities and track the owner's grant-related correspondence, applications and funding decisions. It is not offered as a public account-linking service. The server integration is restricted to the owner's connected Gmail account. This website provides application and privacy information; it does not collect Gmail credentials or offer Google sign-in.

Google data access

The server requests only https://www.googleapis.com/auth/gmail.readonly. Google grants this permission at mailbox level; it is not a permission limited to one Gmail label. Grant Seeker limits its routine processing to the owner's Grant Seeker/Review, Grant Seeker/Verified and Grant Seeker/Action Required labels, with a 30-day lookback. It excludes drafts, sent mail, spam and trash from routine scans.

For labeled grant correspondence, the server may read message and thread identifiers, label identifiers, sender address, subject, received time and authentication headers. It reads message text only after the configured sender-authentication check succeeds. It does not download attachments. Unverified senders and unmatched applications are held for review. The owner may explicitly authorize synthetic integration tests using a clearly identified unsent draft.

The connected ChatGPT workflow separately inspects messages matching grant-related event criteria, checks relevance and legitimacy, and organizes grant mail with Gmail labels. That workflow operates through the owner's separately authorized ChatGPT Gmail connection, not the server's OAuth credential.

How the information is used

Google data is used to identify application acknowledgments, requests for documents, interview invitations, deadlines, funding decisions and payment notices; match messages to grant applications; update tracking records; prepare activity summaries; and notify the owner about actions requiring attention. A notification is not proof of an award or cleared payment. The server does not send email or submit grant applications.

Grant Seeker does not sell Google user data, use it for advertising, or use it to train or improve generalized artificial-intelligence or machine-learning models. Owner-directed ChatGPT assistance is used for the grant workflow, not to provide a public AI training dataset.

Grant Seeker's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements: https://developers.google.com/terms/api-services-user-data-policy.

Storage and service providers

The owner's Hostinger server stores OAuth credentials, private sender/application mappings, processing identifiers and local workflow state. OAuth credentials are kept outside the code repository in root-owned private files and made available to the isolated service through systemd's private credential mechanism. Access tokens are used in memory.

The owner's Airtable Grant Seeker base stores concise correspondence summaries, sender/subject information, dates, action flags, message identifiers, Gmail links, application tracking notes and evidence-backed award records. Full email bodies and attachments are not intentionally stored by the server integration in Airtable or its application logs.

The owner's authorized ChatGPT/OpenAI connections process grant correspondence for relevance checks, notifications, summaries and owner-requested assistance. ChatGPT conversation and task records are subject to the owner's OpenAI account controls and the provider's policies.

The public application-information pages are hosted by GitHub Pages. No Gmail authorization tokens, correspondence or application documents are published there. The information website adds no advertising or analytics scripts; the hosting provider may process normal web-request information under its own policies.

Retention and removal

There is currently no automatic time-based deletion schedule for local tracking state, Airtable records or ChatGPT records. The owner controls retention and can delete those records using the relevant service or administration tools. Credentials remain until the owner replaces or removes them. After the owner revokes Google access, the owner must also stop the integration and remove invalid credentials from the server. Revoking OAuth access does not automatically delete previously created tracking or ChatGPT records.

The owner can revoke Google access at https://myaccount.google.com/connections. To request assistance removing Grant Seeker data or correcting records, contact fotetech@gmail.com. Data held in provider backups or service logs is handled according to the relevant provider's retention rules.

Security and changes

Grant Seeker limits permissions and processing, verifies configured senders, keeps credentials outside GitHub and application logs, uses HTTPS for API communication, and isolates the server worker. No system can guarantee absolute security. This notice should be updated before the app's audience, scopes, providers or data uses change. Adding other Google users or public distribution requires a fresh review of Google's verification requirements.
